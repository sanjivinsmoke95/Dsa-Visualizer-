# DSA Visualizer UI

A modern React/Tailwind interface for experimenting with data-structure and algorithm visualizations.

## UI direction

- Warm cream canvas with clean enterprise-style surfaces
- Deep green primary actions with saffron accents
- Rounded cards and controls
- Manrope for UI typography
- IBM Plex Mono for technical identifiers
- Source Serif 4 for document/evidence-style text

## Origin

The visual system in this repository is a standalone extraction of the UI refinement work developed for MORPHEUS, adapted here without MORPHEUS product logic or backend behavior.
